一、第一次怎么打开

🌐 有免安装的网页版！直接打开 https://minghe-lgt.github.io/print-studio/ 就能用（推荐手机/图省事）。注意：数据保存在浏览器里， 换电脑或清缓存会丢，请常到「⚙️ 设置 → 导出数据」备份；电脑上想存文件就用下面的下载版。
1
电脑装一次 Python（去 python.org 下载，安装时务必勾选 Add python.exe to PATH）
2
以后每次想用，双击 start.bat，浏览器会自动打开网站
3
用完直接关掉黑色窗口就行，数据不会丢
📱 手机也能用：手机连同一个 WiFi，用启动时黑窗口里显示的「手机访问」网址打开（第一次会弹防火墙提示，点「允许访问」）。
🧹 第一次打开里有几条带「示例」的数据，是给你演示用的，看懂之后随手删掉或改掉就行。

二、每天就做三件事

别被十个页面吓到，其实日常只有三个动作，每个都有捷径：

什么时候做什么在哪点
买了耗材 / 配件记一笔采购，到货后点「确认收货入库」首页「🛒 记一笔采购」一步直达
打印完成了任务点「完成」，材料和成品自动进出库首页「🖨️ 新建打印任务」
卖出去了记一笔销售，顺手填快递单号首页「💰 记一笔销售」一步直达
💰 首页最上面四张卡就是今天的答案：卖了多少、赚了多少、库存值多少钱。缺料、欠货、该保养打印机，都会在「待办提醒」里喊你。

三、买了材料怎么记

1
第一次用先去「🧱 物料库存」→「新增物料」，把常用耗材建一遍：名称（如 PLA 玛雅棕）、类别选「耗材」、每卷克重（如 1000）、单价。
2
下单买了就去「🛒 采购记录」→「新增采购单」。耗材默认按卷填：填 2 卷、每卷 20 元，系统自动换算成克和元/克，不用自己算。
3
快递到了，回到采购单点 「✅ 确认收货入库」 —— 材料自动入库，以后打印消耗、库存预警都靠它。
⚠️ 耗材的库存按「克」记（会自动显示 ≈ 几卷），因为打印是按克耗料的；配件、工具按「个」记。

四、打印完怎么记

1
开打之前：去「🖨️ 打印任务」→「新建打印任务」，写标题、选打印机、填预计耗材克数（切片软件里能看到）。
2
打完之后：点 「✅ 完成」，填成品几件、废件几件、耗时。系统自动：扣减材料 → 成品入库 → 算出单件成本。
3
打坏了就填废件数，经营分析页会统计废件率，太高会提醒你。
🖨️ 打印机累计打印到一定小时数（默认 200h，可在设置里改），首页会提醒你保养、检查喷嘴。

五、卖货怎么记（含发货）

1
出单了：首页「💰 记一笔销售」，选商品（会显示库存）、填单价（商品设过价会自动带出）。系统自动扣库存、算利润。
2
发货后：销售列表点 「📦 发货」，填快递单号。看板会一直显示「待发货 N 单」，不会漏发。
3
先接单后打印？库存不够也能录，系统会问「按预售记录吗」，确认后进「欠货清单」，打印入库后自动冲销。
🐟 去看看「📦 成品商品」页：商品可以 Ctrl+V 粘贴图片、📝 一键生成闲鱼文案（材料、包装、售后话术都写好了）、把闲鱼链接贴回来以后一键打开改价。

六、怎么挑模型 / 收藏模型

都在「🌐 模型收藏」页：

想做什么怎么点
看看现在什么火「🔥 站内刷模型」→ 点「搜一下」= 总热榜；填关键词（如 dragon、收纳）= 站内搜索，可按热门/最新/评分/最多人做排序，喜欢直接「＋收藏」
去各大模型站逛「🔥 逛热门挑货」一键打开 MakerWorld、Printables、Thingiverse、Cults3D 的热门页
有链接想存起来「＋添加模型收藏」→ 粘贴链接 → 点「🔍 自动获取」自动填名称和封面图
自己不会建模「🤖 AI 直接生成模型」：丢一张图片就能生成 3D 模型（混元3D / TRELLIS / Tripo / Meshy）
管理打印节奏收藏的模型有状态：想打 → 打印中 → 已上架；随手记「💡 建模点子板」

七、卖多少钱怎么算

去「🧮 定价计算」：填克重、时长、选材料和打印机（电价、机时费在⚙️设置里配好一次就行），右边直接给出成本明细和建议售价。

建议：成本 × 2 起步（目标利润率 100%），再点「取整到 x.9」——比如成本 4.4 元就卖 8.9 元。觉得卖不动再往下调，别低于成本。

八、怎么看赚了还是亏了

📊 经营看板 = 今天的状态；📈 经营分析 = 这几个月的账：

  • 近 6 个月销售 / 采购 / 利润趋势
  • 畅销商品排行 —— 该多打什么一目了然
  • 渠道占比 —— 闲鱼、微信哪个来钱多
  • 废件率、毛利率 —— 自动给经营建议

每一笔操作在「📜 全站流水」都能查到，也能导出 Excel（CSV）。

九、数据备份与恢复

✅ 好消息：每次启动软件都会自动备份到 data\backups\ 文件夹，保留最近 10 份，基本不用操心。

手动备份：点右上角「💾 备份」，把下载的 .db 文件存到网盘/U盘。

恢复：关掉程序 → 把备份文件重命名为 studio.db → 替换 data 文件夹里的同名文件 → 重新打开。

十、常见问题

Q：双击 start.bat 一闪就没了？
A：多半没装 Python 或没勾 PATH，重装 Python 勾上即可。

Q：手机打不开网站？
A：确认连的同一个 WiFi；第一次运行时防火墙弹窗要点「允许」；不行就把防火墙里 Python 的入站规则放开。

Q：提示「端口已被占用」？
A：说明网站已经在运行了，直接浏览器打开 http://127.0.0.1:8765。

Q：单价到底填什么？
A：采购单里耗材默认按卷（填几卷、每卷多少钱）；想按克填就点旁边的「按克输入」切换。

Q：示例数据能删吗？
A：能，全部可编辑可删除，删干净就是空白账本。

Q：录错了怎么办？
A：销售可删（库存自动返还）；材料库存错了用「⚖️盘点」改成正确值；已完成的打印任务不能删（涉及库存流水），录错数量可以再打印一单冲回来，或用盘点修正成品。

⚠️ 安全提醒：本网站只适合在自己家 / 工作室的 WiFi 里用，不要把端口开放到公网。
