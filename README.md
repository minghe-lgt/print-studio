# 打印小站 · 3D 打印工作室管理网站

专为「自己买打印机、在闲鱼等平台卖成品」的小工作室做的轻量管理网站。
**零依赖、双击就能用、数据全部存在自己电脑上。**

## 能做什么

| 模块 | 说明 |
|---|---|
| 📊 经营看板 | 本月采购/销售/利润、库存价值、**欠货/缺料/保养**提醒、待发货单数、近 7 日销售图 |
| 🧱 物料库存 | 耗材按「克」记账（自动换算成卷）、配件工具按个；入库/出库/盘点，低库存自动提醒 |
| 🛒 采购记录 | 录采购单 → 货到点「确认收货入库」→ 自动入库并更新最新单价 |
| 🖨️ 打印任务 | 打印机管理（含累计时长和保养提醒）；完成任务时按克重自动扣减耗材、成品自动入库，并算出单件成本 |
| 📦 成品商品 | 商品图 **Ctrl+V 粘贴上传**、一键**生成闲鱼文案**、挂闲鱼链接一键打开、库存欠货一目了然 |
| 💰 销售记录 | 出单自动扣库存算利润；**缺货可按预售接单**（自动进欠货清单）；**发货状态 + 快递单号** |
| 📈 经营分析 | 近 6 个月销售/采购/利润趋势、畅销商品排行、渠道占比、废件率、毛利率和经营小结 |
| 🌐 模型收藏 | 收藏模型链接（自动抓标题+封面）、状态跟踪、点子板；**站内刷/搜 Printables 模型**（实验性，关键词+热门/最新/评分/最多人做排序，可一键收藏）；一键去 MakerWorld/Printables/Thingiverse/Cults3D 搜索或逛热门；AI 图生 3D 工具入口 |
| 🧮 定价计算 | 材料 + 电费 + 机时 + 人工 + 损耗 → 建议售价，一键取整到 x.9 |
| 📜 全站流水 | 每一笔操作都自动记录，可筛选、可导出 CSV |

## 怎么启动（朋友看这里）

1. 装一次 [Python](https://www.python.org/downloads/)（安装时勾选 **Add python.exe to PATH**）
2. 双击 **`start.bat`** —— 浏览器会自动打开网站；网站右上角有 **📖 说明书** 按钮（图文版：`static/使用说明书.html`，也可直接双击打开）
3. 想用手机操作？手机连**同一个 WiFi**，用启动时窗口里显示的「手机访问」地址打开
4. 用完直接关掉黑窗口即可，数据不会丢

> 第一次打开里面有几条带「示例」的数据，是用来演示的，可以直接编辑或删掉。

## 数据备份（重要！）

- **每次启动都会自动备份**到 `data/backups/`，保留最近 10 份，放心用
- 也可点右上角 **💾 备份** 手动下载一份收好
- 恢复：把备份文件重命名为 `studio.db`，替换 `data` 文件夹里的同名文件（先关闭程序）
- 所有表格都能在「全站流水」页导出成 CSV，用 Excel 打开

## 常见问题

- **双击后窗口一闪而过**：多半是没装 Python 或没勾 PATH，重新安装 Python
- **手机打不开**：第一次运行时 Windows 防火墙弹窗要点「允许访问」；或在防火墙设置里允许 Python
- **端口被占用**：窗口会提示「可能已在运行」，此时直接开浏览器访问 `http://127.0.0.1:8765` 即可
- **安全提醒**：本站只建议在家里/工作室局域网内使用，不要把端口暴露到公网

## 技术说明（给以后维护的人）

- 后端：Python 标准库（`http.server` + `sqlite3`），单文件 `app.py`，无 pip 依赖
- 前端：`static/` 下的原生 HTML/CSS/JS 单页应用，无构建步骤、无 CDN
- 数据库：`data/studio.db`（SQLite 单文件）
- 手动启动：`py app.py [端口]`，加 `--no-browser` 不自动开浏览器
